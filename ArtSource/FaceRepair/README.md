# Face and blink repair

Open `Face_Repair.blend`. The scene selector contains the eight reference characters. Textures are packed.

- Frame **1**: open eyes, including the repaired sporty eyebrows.
- Frame **12**: the previous closed-eye texture.
- Frame **24**: the repaired closed-eye texture.

The original mesh shapes and rigs are retained. This pass repairs eyelid texture seams, reduces oversized lash lines, protects neighbouring atlas islands, and restores the original eyebrow artwork on all ten sporty variants. It does not remodel faces or repaint the existing scalp/hairline artwork.

The 44 tourist closed-eye textures in `Assets/_Game/Avatar/Bodies` are generated by `MeshyCharacters.ClosedEyes.cs`. The fill is continuous in face coordinates, with depth filtering, robust local skin-colour gradients, and four pixels of padding into empty UV gutters. The ten sporty GLBs contain the Blender-authored eyebrow correction. Their previous GLBs are preserved in `Originals`.

## Rebuild

1. Run Blender with `--background --python ArtSource/Tools/blender_repair_sporty_brows.py` to repeat the eyebrow repair from its preserved originals.
2. In Unity, run **PLEASE DON'T DROWN / Repair tourist eyelid textures**.
3. For the automated eight-character review, run `PleaseDontDrown.Editor.MeshyCharacters.BakeFaceRepairAll` with `-shots Screenshots/Review/FaceRepair/shots.txt` and log to `Screenshots/Review/FaceRepair/final2.log`.
4. Run Blender with `--background --python ArtSource/Tools/blender_face_review.py` to refresh this comparison file.

`verify_face_repair.py` checks the ten GLB exports for unchanged triangle counts, surface positions within 0.01 mm, bone transforms, normalized skin weights, texture resolution, and localized texture edits. Review renders, logs and validation reports are in `Screenshots/Review/FaceRepair` (ignored by Git). The previous eyelid textures and generator are backed up there under `Originals`.

Validation covers asset import and rendered open/closed expressions; no player build or full gameplay session was run.
